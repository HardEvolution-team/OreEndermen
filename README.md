# Ore Endermen Port

Unofficial Minecraft 1.12.2 (Cleanroom) port of **Ore Endermen Mod** by its original author.

- Original: https://www.9minecraft.net/?p=71751
- Requires [ArchaicLib](https://www.curseforge.com/minecraft/mc-mods/archaiclib) 1.25.0+

This port contains **no original assets**. Put your own copy of the original jar (`ore_endermen_mod_1.7.10.jar`) into `.minecraft/archaic_originals/`; ArchaicLib reads textures/sounds from it at runtime.
